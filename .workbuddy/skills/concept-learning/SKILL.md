# 概念学习资料生成 Skill（concept-learning）

本 Skill 把"我学一个新概念时应该问什么、看什么、产出什么"固化成一套可复用的流程。
它体现的学习理念：**先框架后细节、用自己的话解释（费曼技巧）、一切结论可回溯到来源。**

## 一、适用场景

- 学到一个新概念（如 Agent、上下文、RAG、微调、Tokenizer……），想系统理解而不是碎片化浏览；
- 需要把学习成果沉淀成一份可复习、可分享、可迭代的资料；
- 概念容易和别的概念混淆，需要专门的辨析；
- 后续还会学习更多概念，希望所有资料结构统一、方便横向对比。

**不适用**：纯操作类教程（如"如何安装 Node.js"）、开放性观点讨论、与 AI/技术无关且来源难以核查的概念。

## 二、输入信息

| 输入 | 是否必填 | 说明 |
| --- | --- | --- |
| 概念名称 | 必填 | 一个词或短语，如"大模型的上下文" |
| 学习背景 | 可选 | 学习者的身份与已有水平（默认：上过 AI 导论课的大学生） |
| 关注侧重 | 可选 | 原理 / 应用 / 辨析，默认均衡覆盖 |
| 输出语言 | 可选 | 默认简体中文 |

**一词多义处理**：若概念在不同领域含义不同（如"上下文"在 NLP 与操作系统中含义不同），先向用户确认指哪个领域，再开始生成。

## 三、生成步骤（工作流程）

1. **定位概念**：确认概念所属领域、指代边界，必要时与用户确认。
2. **检索并筛选来源**：按优先级收集 3–6 条来源 —— 官方文档 > 经典论文（arXiv 等）> 权威工程博客 > 其他。**每条链接必须逐一核实可访问后才能引用**。
3. **建立学习框架**：写 3–5 条学习目标（学完应能做到什么）+ 3–5 个核心问题（学完应能回答什么）。
4. **撰写个人化解释**：用第一人称、用自己的话和一个贴切的类比解释概念；**禁止整段照搬来源原文或 AI 对话原文**。
5. **拆解核心机制/组成**：说明概念由哪些部分构成、如何运转，配表格或示意图。
6. **给出一个具体应用场景**：优先选用学习者亲身经历的真实场景，要有时间、人物、动作，而不是空泛的"在企业中广泛应用"。
7. **概念辨析与使用边界**：列出 2–4 个最常见的混淆点做对比；说明概念何时不适用、容易失效的边界。
8. **设计课后自测（互动选择题）**：3–5 道与学习目标对应的**单选题**，以可交互形式呈现——点击选项即时判分（正确标绿、错误标红），自动展开答案解析，全部作答后显示得分，并提供"重新作答"按钮。每题必须：① 有 4 个选项且只有一个正确答案；② 干扰项对应常见误解（而非随意编造）；③ 解析中先给出正确答案，再说明理由、指出错误选项错在哪里。实现方式为页面内嵌原生 JavaScript，禁止依赖任何外部库或网络请求（保持文件自包含）。
9. **整理参考来源**：列表呈现，每条注明 URL 及它支撑了资料中的哪一部分内容。
10. **自检与交付**：按"自检要求"逐项核对，全部通过后将文件保存到 `learning-materials/<概念-slug>.html`，并向用户提示需要人工核查与修改。

## 四、输出结构

输出为**单个自包含 HTML 文件**（内联 CSS，无外部依赖，双击即可在浏览器打开），区块及顺序固定：

1. **头部**：概念名、一句话定位、生成日期、所使用的 Skill 名称
2. **学习目标**
3. **核心问题**
4. **我的解释**（个人化，第一人称）
5. **核心机制与组成**（含表格或示意图）
6. **具体应用场景**
7. **概念辨析与使用边界**（对比表 + 文字）
8. **课后自测**（互动选择题：点击作答、即时判分、自动展开答案解析、统计得分，可重做）
9. **参考来源**（逐条标注支撑内容）
10. **人工核查记录**（AI 生成后由本人核查、修改了什么的说明）

## 五、资料来源要求

- 数量 3–6 条，优先官方文档、经典论文、权威工程博客；
- **不得伪造来源**：所有链接必须真实存在且在生成时核实过可访问；
- 每条来源要标注它支撑了资料中的哪部分内容，便于回溯核查；
- 资料中的关键事实（数字、定义、机制描述）应能对应到至少一条来源。

## 六、自检要求

生成完成后逐项核对，未通过则返工：

- [ ] 个人解释是否完全用自己的话？一个外行能否读懂？
- [ ] 机制描述是否与来源一致？有无夸大或过时？
- [ ] 应用场景是否具体（有时间、人物、动作），而非空话？
- [ ] 辨析是否覆盖了最常见的 2–3 个混淆点？
- [ ] 每条参考链接是否逐一核实过（HTTP 200）？
- [ ] 自测题是否与学习目标一一呼应？每道选择题是否只有一个正确答案，且解析准确、干扰项对应真实误解？
- [ ] 互动逻辑是否本地可用（无外部依赖）：点击能判分、解析能展开、得分能统计、重做能复位？
- [ ] 是否提醒用户进行人工核查并在"人工核查记录"中登记修改？
- [ ] 文件是否为自包含 HTML，无外部依赖、无敏感信息？
